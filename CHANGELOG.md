# Changelog

All notable changes to the Open Triage Skills collection are documented here.
Format: emoji-category bullet list per release, newest first — the same shape
the `ot-auto-update-changelog` skill generates.

## 1.0.0 (2026-09-10)

Initial Open Triage release.

- 📦 Thirty-seven skills covering the full AI SDLC pipeline — plan, implement,
  review, QA gate, merge — installable into any repo with any coding agent.
- 📝 Based on the [open-mercato/skills](https://github.com/open-mercato/skills)
  collection (MIT), rebranded for Open Triage: skill prefix `om-` → `ot-`,
  repositories → `triage-software/{skills,open-triage}`, distinct logo, fresh
  MIT license. Port decisions and provenance: [DECISIONS.md](DECISIONS.md).
